# Anteprima pubblica del metallo liquido

Pagina autonoma: liquid-metal.html, liquid-metal.css e liquid-metal.js.
Usa GSAP e i font già presenti nel repository. Non carica gli script di
allenamento, autenticazione, backup o sincronizzazione. Non legge né scrive
localStorage e non registra service worker. Tutti i campi sono dimostrativi.

La copia del motore corrisponde a js/liquid-metal.js in sviluppo. La versione
principale dell'app non viene aggiornata pubblicando questa anteprima.

URL: https://rolli-pierpaolo.github.io/Scheda-Palestra/preview/liquid-metal.html

Per verificare localmente dalla radice: python -m http.server 8767.
